# Reference marks

The Cathay brushwing and oneworld marks are bundled locally for this unofficial
UI mockup, so rendering does not depend on remote image servers. All trademarks
remain the property of their respective owners; their presence does not imply
endorsement or a valid travel document.

- `cathay-brushwing.svg`: brushwing path from the official Cathay header asset,
  with numeric precision reduced and the surrounding anniversary artwork removed:
  https://www.cathaypacific.com/content/dam/header-footer-lrp/cathay80-en.originalimage.svg
- `oneworld.svg`: official Cathay-hosted alliance mark:
  https://www.cathaypacific.com/content/dam/header-footer-lrp/Oneworld.originalimage.svg

The Cathay Pacific wordmark is typeset locally. The small footer tile uses the
brushwing instead of reproducing the reference's dated anniversary app icon.
The user's reference screenshot and its personal data are not included.
